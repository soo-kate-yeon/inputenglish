## REQ-WEB-001 — 웹 사용자 인증 / 계정

### AC-001-1 (OAuth 로그인 → 세션·프로필 생성)
- **Given** 신규 사용자가 로그인 페이지에서 "Google로 계속하기"를 누른다
- **When** OAuth PKCE 콜백이 성공적으로 도착한다
- **Then** 쿠키 세션이 수립되고 `UserProfile`이 생성(plan=FREE, created_at=now)되며 온보딩으로 분기된다

### AC-001-2 (SSR·API 세션 일관성)
- **Given** 로그인된 사용자가 학습 홈(SSR)을 연 상태다
- **When** 같은 세션으로 `/api/premium/today`를 호출한다
- **Then** 동일 쿠키 세션이 인증되어 `requireApiUser`를 통과한다 (Phase 1 Task 1.0 선검증 대상)

### AC-001-3 (이메일 OTP)
- **Given** 사용자가 "이메일로 시작하기"로 이메일을 입력한다
- **When** 매직링크/OTP 인증을 완료한다
- **Then** 세션이 수립되고 학습 홈 또는 온보딩으로 이동한다

### 엣지 케이스
- **EC-001-A (비로그인 보호경로):** 비로그인 상태로 학습·결제 경로 접근 시 /login으로 리다이렉트된다 (W1).
- **EC-001-B (세션 만료):** 만료 세션으로 보호 API 호출 시 콘텐츠 대신 401이 반환되고 재로그인이 유도된다 (U2).
- **EC-001-C (기존 유저 재로그인):** 이미 `UserProfile`이 있는 유저는 중복 생성 없이 upsert로 처리된다.

## REQ-WEB-002 — IL 7밴드 자가배치 + 온보딩

### AC-002-1 (샘플클립 자가배치 → IL 시드)
- **Given** 온보딩 밴드 단계에서 사용자가 IL 4 카드의 20~30초 임베드 클립을 본다
- **When** "편하다"를 선택한다
- **Then** IL 시작점 시드 = 4.0으로 기록된다 (E1)

### AC-002-2 (어휘진단 교차검증 — 낮은 쪽)
- **Given** 자가선택 IL = 5, 어휘진단 추정 IL = 3
- **When** 시스템이 두 값을 교차검증한다
- **Then** 시작 IL = 3(낮은 쪽)으로 설정된다 (E2, U3 — 좌절=이탈 방지)

### AC-002-3 (탭센서 소수점 보정)
- **Given** 사용자 IL = 4.0이고 콘텐츠 탭률(모르는 단어 비율)이 1%로 측정된다
- **When** 시스템이 IL을 미세조정한다
- **Then** IL 소수점이 상향(예: 4.0→4.2)된다 (W1, 목표 2~5%)

### 엣지 케이스
- **EC-002-A (앞면=실존 앵커):** 밴드 카드는 "B1" 같은 추상 라벨이 아니라 Peppa Pig/TED 등 실존 콘텐츠로 제시된다 (U2).
- **EC-002-B (자가선택 과대평가):** 자가선택이 진단보다 높게 엇갈리면 절대 높은 쪽으로 시작하지 않는다 (U3).
- **EC-002-C (7밴드 마이그레이션):** 기존 4밴드(level_band) 유저가 IL 7밴드로 시드 호환 매핑되며 데이터 손실이 없다.

## REQ-WEB-003 — 화이트리스트 + 법적 입장규칙 + 세그먼트 인덱스

### AC-003-1 (세그먼트 단위 인덱싱 + script_clean)
- **Given** 공식 채널의 임베드 활성 영상이 인제스트된다
- **When** 시스템이 세그먼트를 인덱싱한다
- **Then** `VideoSegment`(start/end, transcript, **script_clean**, wpm, band coverage, IL, self_contained, 자막의존단계)가 저장된다 (U2)

### AC-003-2 (입장규칙 3줄 차단)
- **Given** 후보 채널이 "Peppa Pig Full Episodes 3hr"(팬 재업로드)이다
- **When** 시스템이 입장규칙을 검증한다
- **Then** 비공식/재업로드 사유로 화이트리스트에 포함되지 않는다 (U3)

### AC-003-3 (리스닝 임계 — 리딩보다 높게)
- **Given** 세그먼트 어휘 커버리지가 96%(리딩 기준 통과)이다
- **When** 리스닝 난도 게이트를 적용한다
- **Then** 리스닝 임계(≈98~99%) 미달로 더 쉬운 난도/낮은 wpm 요구가 적용된다 (E1)

### 엣지 케이스
- **EC-003-A (대형 IP 제외):** 디즈니 공식 클립이어도 대형 IP 사유로 out (U3).
- **EC-003-B (자체 플레이어 금지):** 영상을 iframe 아닌 자체 플레이어로 감싸려 하면 차단된다 (U4 — ToS).
- **EC-003-C (자족성 게이트):** "아까 그것…"으로 앞을 가리키는 세그먼트는 추천되지 않는다 (W1).

## REQ-WEB-004 — 하루=하나의 콘텐츠 유연 사다리

### AC-004-1 (기본 3단 사다리 + 클린스크립트 리딩)
- **Given** 보통 난도의 오늘 콘텐츠가 배정되었다
- **When** 사용자가 학습을 시작한다
- **Then** 0 예습 → 1 RWL(자막ON·탭글로스) → 2 무자막 3단으로 구성되고, 리딩은 그날 세그먼트 **script_clean**이며 별도 생성 리딩이 없다 (U1, U2)

### AC-004-2 (시스템 주도 무자막 전환)
- **Given** 사용자가 RWL(1단)을 완료하고 난도모델이 전환 시점으로 판단한다
- **When** 다음 단계로 진행한다
- **Then** 시스템이 같은/인접 세그먼트의 무자막(2단)을 *주도적으로* 제시한다(유저 토글 의존 아님) (E2)

### AC-004-3 (하이라이트 질문 — 하루 10회 캡)
- **Given** 사용자가 오늘 9번째 질문을 보낸다
- **When** 시스템이 짧은 답을 반환한다
- **Then** `AskedItem` 저장 + "오늘 질문 1개 남음" 긍정 표시 (E3, W2)

### 엣지 케이스
- **EC-004-A (어려운 콘텐츠 0.5단):** IL 상한 근처·높은 탭률에서 시스템이 스크립트 선행읽기(클린본)를 RWL 전에 꺼낸다 (W1 — 매일 강제 아님).
- **EC-004-B (캡 초과 graceful):** 11번째 질문은 하드 차단 없이 경량 모델 강등 또는 "내일 다시" 완곡 안내로 응대된다 (U4).
- **EC-004-C (금지 surface):** 학습 화면에 카드·회상 퀴즈·표현 사전 큐레이션이 노출되지 않는다 (U3).

## REQ-WEB-005 — 코스×밴드 격자 + 세션 조립 + entitlement

### AC-005-1 (세션 조립 = 리딩 1 + 세그먼트 N)
- **Given** 권한 있는 사용자 IL=4, 코스=뉴스
- **When** 오늘 세션을 요청한다
- **Then** 뉴스 레인 IL≈4 세그먼트가 매칭·랭킹(fun 최종)되어 `Session`(reading=script_clean + [segment...])이 반환된다 (E1)

### AC-005-2 (entitlement 게이트)
- **Given** 체험 만료·미구독 사용자
- **When** 오늘 세션을 요청한다
- **Then** 콘텐츠 대신 결제/구독 안내가 반환된다(402) (U2, U3)

### 엣지 케이스
- **EC-005-A (빈 격자칸):** IL 1 "업계 팟캐스트"처럼 빈 칸은 사용자에게 노출되지 않는다 (W1).
- **EC-005-B (코스 완주 → 재구매 동선):** 코스 완주 임박 시 다음 코스가 추천된다 (O1).
- **EC-005-C (고정 커리큘럼 아님):** 같은 IL·코스라도 엔진이 레인 안에서 i+1 선별을 유지한다 (U1).

## REQ-WEB-006 — 주간 예습자료

### AC-006-1 (주 시작 생성 + 맥락 묶음)
- **Given** 새 주차가 시작된다(일요일)
- **When** 시스템이 그 주 콘텐츠에서 예습자료를 생성한다
- **Then** 밴드 맞춤 `WeeklyPrep`(어휘·표현 + 각 항목의 실제 소스 문장)이 생성된다 (E1)

### AC-006-2 (웹 제공 + 발송)
- **Given** `WeeklyPrep`가 준비되었다
- **When** 발송이 트리거된다
- **Then** 웹에서 열람·PDF 다운로드 가능하고, 카톡·메일로 "이번 주 예습 나왔어요" + 핵심표현 일부가 발송되며 발송상태가 기록된다 (U1, E2)

### 엣지 케이스
- **EC-006-A (단순 단어나열 거부):** 밴드·맥락 없이 단어만 나열된 자료는 발행되지 않는다 (U2).
- **EC-006-B (발송 실패 기록):** 발송 실패 시 상태가 실패로 기록되고 재시도 대상이 된다.

## REQ-WEB-007 — 리마인드 (카톡 + 이메일)

### AC-007-1 (주제 스토리텔링 + 폴백)
- **Given** 일일 리마인드 시각이 도래한다
- **When** 시스템이 발송한다
- **Then** "오늘 BBC에서 이런 일이—" 식 주제 호기심 본문으로 **Solapi 알림톡**이 발송되고, 실패 시 **Resend 이메일**로 폴백된다 (E1)

### AC-007-2 (가치완결형)
- **Given** 사용자가 리마인드를 받았으나 링크를 클릭하지 않는다
- **When** 메시지를 읽기만 한다
- **Then** 본문 안에서 오늘 표현 1개·한 문장을 건진다 (U1)

### 엣지 케이스
- **EC-007-A (opt-out):** 학습 리마인드 수신 거부 유저에게는 학습 리마인드가 발송되지 않는다 (W1).
- **EC-007-B (이중 실패 에스컬레이션):** 알림톡·이메일 모두 실패하면 로깅 + 운영 알림으로 에스컬레이션되고 무한 재시도하지 않는다 (U3).
- **EC-007-C (광고성 금지):** 알림톡 템플릿에 광고성 문구가 포함되지 않는다(정보성) (U2).

## REQ-WEB-008 — 구독 결제 (토스페이먼츠 약정 + 자동갱신)

### AC-008-1 (약정 결제 → entitlement 활성)
- **Given** 사용자가 연 79,000원 약정을 선택한다
- **When** 토스 결제 후 서버 `POST /v1/payments/confirm` 검증을 통과한다
- **Then** `subscriptions`(약정=연, 만료일=+1년)와 entitlement가 활성화된다 (U1, E1)

### AC-008-2 (7일 무료체험 1회)
- **Given** 가입 후 3일 경과한 미결제 사용자
- **When** 콘텐츠에 접근한다
- **Then** 체험 잔여 4일과 함께 접근이 허용되고 결제 전환 CTA가 표시된다 (W1, D12)

### AC-008-3 (자동갱신 빌링키)
- **Given** 자동갱신 동의로 billingKey가 저장된 사용자의 약정 만료일이 도래한다
- **When** 갱신 Cron이 실행된다
- **Then** 사전 고지 후 billingKey로 동일 약정 자동결제가 승인되고 만료일이 갱신된다 (E3, E4, D13)

### 엣지 케이스
- **EC-008-A (월 구독 미제공):** 월 구독 옵션은 존재하지 않으며 3개 약정만 제공된다 (U1, D16).
- **EC-008-B (결제 검증 실패):** confirm/웹훅 서명 검증 실패 시 구독이 활성화되지 않는다 (U2).
- **EC-008-C (중복 결제 멱등):** 동일 멱등키 중복 요청이 중복 과금을 만들지 않는다 (U2).
- **EC-008-D (체험 1회 제한):** 체험을 이미 소진한 유저에게 체험이 재부여되지 않는다 (D12).
- **EC-008-E (친구추천 Deferred):** 추천코드는 스키마/자리만 존재하고 크레딧 지급은 MVP에서 동작하지 않는다 (O1).
